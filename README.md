# Asterion — установка и обновления

## Как установить

1. Откройте **[последний релиз](https://github.com/Artem-Makarov/asterion-releases/releases/latest)** и скачайте файл `Asterion-Setup-…exe`.
2. Запустите его. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»** (у установщика нет платной цифровой подписи).
3. Нажимайте «Далее» до конца — на рабочем столе появится ярлык **Asterion**.
4. При первом запуске программа определит вашу видеокарту и предложит скачать подходящие бесплатные модели для картинок, видео и озвучки — нажмите «Настроить».

Права администратора не нужны. Нужна Windows 10 или 11 (64-бит).

## Обновления

Ничего скачивать вручную не нужно: когда выходит новая версия, Asterion сам предложит обновиться (или **Настройки → Обновления**). Проекты, настройки и модели при обновлении сохраняются.
